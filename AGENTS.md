# Public source maintenance

This repository is a generated, sanitized source snapshot. Preserve upstream license and attribution files.

Never add credentials, account configuration, private memories, conversations, databases, uploads, deployment records, real hostnames, or personal identifiers.

Deployment paths, the service account, the example domain and the zero disk UUID are placeholders. Review and configure them for your own host before deployment. Native host execution is privileged; separate login configuration does not provide host filesystem isolation.

Changes to the public mirror do not synchronize back to its private source. Source publication must use the reviewed export allowlist and pass privacy and secret checks. Run the web unit tests and build after changing generated source.
