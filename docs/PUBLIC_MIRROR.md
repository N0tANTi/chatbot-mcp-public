# 公开源码同步

此仓库采用私有源 → 脱敏导出 → 扫描 → 公开快照的单向发布方式。公开分支包含独立历史，不携带私有仓库的提交、分支、作者记录或运维文档。

发布器只读取 Git 已提交且在清单中批准的源码。私人记忆和导出目录、数据库、配置凭据、上传文件及运维记录不属于发布范围。真实服务账号、部署域名、项目标签和主机磁盘标识被替换成示例值。

新的网页/桥接源码文件会阻止发布，直到明确加入审核清单；二进制资源固定校验值，变更后须再次审核。已有文本文件会经过已知标识检查和 Gitleaks 密钥扫描，失败时不会推送。自动扫描不能识别所有语义上的个人信息，公开源码变更仍应保持人工隐私审查。

同步使用仅能写入此公开仓库的专用部署密钥，保存在私有源的 Actions Secret 中，不包含在公开仓库。工作流只由主分支变更或手动运行触发，不运行不可信拉取请求的发布任务。

公开仓库不接受自动双向同步。若要贡献，请将补丁交给维护者审核并合入源仓库；直接修改生成文件可能在后续发布时被替换。许可证、来源声明和字体许可保持原样。
